# AI-Assisted Software Development Lifecycle

## Overview

Designed and implemented an AI-assisted software development
workflow that integrates AI agents into multiple stages
of the engineering lifecycle.

## Technologies

- AWS Kiro
- AI Agents
- GitLab
- Jira
- Confluence
- CI/CD
- Golden Pipelines

## Workflow

1. Requirements analysis and refinement
2. Technical specification generation
3. Architecture and technical design
4. Task decomposition
5. AI-assisted code generation
6. Automated code review
7. Automated testing
8. CI/CD validation

## Business Impact

### Development Lead Time

**Before:** 14–20 days

**After:** 1–3 days

Implemented Golden Pipelines and AI-assisted development
to reduce repetitive engineering work and accelerate
the delivery of production-ready software.
